# Созвон

Локальное расширение Chrome для веб-конференций Microsoft Teams. Открывает ссылки по расписанию, проходит поддерживаемый экран подключения и закрывает вкладки по времени или при резком оттоке участников. У каждой конференции свои условия выхода. Сервер, аккаунт разработчика и установка Node.js для использования не нужны.

## Установка

1. Откройте `chrome://extensions` в Chrome.
2. Включите «Режим разработчика» справа вверху.
3. Нажмите «Загрузить распакованное расширение» и выберите папку `F:\other\skip-sozvon\extension`.
4. Закрепите «Созвон» в меню расширений Chrome.
5. Один раз войдите в Teams **в браузере**, настройте доступы Chrome и проверьте ручное подключение по вашей ссылке.
6. Откройте расширение: укажите постоянную ссылку, дату и время первого входа, повторение и условия выхода. Нажмите «Добавить в расписание».

## Вход и выход по расписанию (версия 0.3)

По умолчанию задание повторяется **каждую неделю в выбранный день и время**. Можно выбрать разовый вход, ежедневный или по будням. Время берётся с местных часов компьютера. При изменении часового пояса компьютера пересоздайте задания.

1. Выберите режим «Вход и выход по расписанию».
2. Вставьте полную HTTPS-ссылку на конференцию на `teams.microsoft.com`, `teams.live.com` или `teams.cloud.microsoft` (сокращённые ссылки других доменов сначала раскройте вручную).
3. Укажите дату первого входа и повторение. При гостевом подключении можно задать имя; для аккаунта Teams поле не требуется.
4. Настройте время выхода и/или правило оттока. При повторении сохраняется интервал между временем входа и выхода: например, вход в 10:00, выход в 11:30 повторится через неделю с тем же интервалом 90 минут. Отток отслеживается только после подтверждённого подключения.
5. Добавьте задание. В списке появятся ближайший вход, условия выхода и результат последнего запуска.

В нужное время расширение открывает отдельную вкладку, выбирает поддерживаемую кнопку «Продолжить в браузере», пытается выключить камеру и микрофон и нажимает «Присоединиться». Успех определяется по появлению элементов управления звонком, а не по факту открытия ссылки или нажатия кнопки. После входа расширение пытается открыть панель участников. Для нескольких заданий используются независимые вкладки и таймеры. Одинаковая ссылка на одно и то же время повторно не добавляется.

**Автовход пока требует проверки на вашей версии Teams.** Если элементы управления не распознаны или невозможно подтвердить отключение камеры и микрофона, расширение не нажимает кнопку входа. Оно не вводит пароль, не подтверждает MFA, CAPTCHA, запросы разрешений Chrome и не обходит зал ожидания. Эти запросы и корпоративные политики могут помешать работе без участия пользователя. Допуск из зала ожидания остаётся за организатором. После 15 минут неподтверждённого входа автоматизация этой вкладки останавливается; вкладка остаётся открытой для проверки. Если время выхода наступило раньше, расширение пытается закрыть вкладку Teams даже до завершения входа.

Расписание хранится локально и восстанавливается при запуске Chrome и обновлении расширения. Если опоздание не больше 5 минут и время выхода ещё не прошло, расширение запускает задание. Более старые входы пропускаются; повторное задание переносится на ближайшую будущую дату. Перед созданием вкладки запуск помечается выполненным: это защищает от дублей при перезапуске фонового процесса. Если процесс аварийно завершился между отметкой и открытием вкладки, запуск может быть пропущен, и его нужно проверить вручную.

«Приостановить» отключает **будущие** входы, сохраняя текущую конференцию и её условия выхода. «Остановить автоматизацию» у открытой вкладки отменяет её автоматические действия и выход, но не меняет будущие повторы и не закрывает вкладку. «Удалить» убирает расписание и останавливает автоматизацию его текущей вкладки, оставляя её открытой. Для изменения времени или ссылки удалите задание и добавьте новое.

После перезапуска **самого Chrome** уже идущие конференции не подхватываются: их вкладки нужно проверить вручную. Будущие задания сохраняются. Перезапуск service worker внутри работающего браузера сохраняет контроль текущих вкладок. Старый режим «Только выход из открытой вкладки» также доступен.

Для обновления нажмите ↻ на карточке расширения в `chrome://extensions`, затем заново откройте его окно. Новых разрешений по сравнению с версией 0.2 не добавлено.

### Обновление до версии 0.2

На `chrome://extensions` нажмите кнопку обновления на карточке «Созвон» (либо удалите расширение и загрузите папку заново). Версия 0.2 добавляет разрешение **«Отладка» (`debugger`)**; если Chrome запросит подтверждение новых прав, разрешите их и включите расширение. Затем заново включите наблюдение.

### Подтверждение выхода в браузере

При автоматическом закрытии расширение временно подключается к выбранной вкладке через `chrome.debugger`. Оно инициирует закрытие и подтверждает браузерный диалог «Выйти с сайта?» (`beforeunload`) командой `Page.handleJavaScriptDialog` с `accept: true`. Это эквивалент выбора «Выйти» в браузерном подтверждении. Вкладки без такого окна также закрываются.

Подтверждение действует только для выбранной вкладки во время запланированного закрытия; обычные окна `alert`, `confirm` и окна других вкладок не подтверждаются. После закрытия или ошибки подключение снимается. Chrome может показать временную полосу отладки. Открытые DevTools или другое отладочное подключение могут помешать — закройте их на вкладке конференции. Если закрытие не подтверждено за 12 секунд, расширение показывает ошибку и останавливает наблюдение вместо сообщения об успешном закрытии.

Это обработка **системного окна браузера**, а не диалога, нарисованного внутри страницы Teams. При ручном закрытии вкладки автоматическое подтверждение не включается. Обработка проверена автоматическими тестами с заглушками API; проверка в живой конференции остаётся необходимой.

## Условия

- **По времени:** выберите дату и местное время компьютера. При достижении времени расширение закрывает вкладку без дополнительного подтверждения.
- **По оттоку:** по умолчанию за последние 120 секунд число участников должно сократиться минимум на 30% и минимум на 3 человека относительно максимума за этот интервал. Наблюдение начинается после включения; более ранние значения неизвестны.
- **Подтверждение:** после обнаружения оттока число должно оставаться ниже порога ещё 30 секунд по умолчанию. Можно указать от 1 до 300 секунд. Проверка выполняется примерно раз в 5 секунд, поэтому короткий интервал сработает при следующем чтении счётчика, а в фоне возможны дополнительные задержки. На вкладке появится кнопка отмены. Рост выше порога отменяет отсчёт; исходный максимум фиксируется на время подтверждения. Порог и интервалы меняются в расширении.
- Если включены оба условия, срабатывает первое. Подтверждение применяется только к оттоку; назначенное время имеет приоритет.
- Кнопка «Отменить автозакрытие» на вкладке останавливает автоматизацию этой вкладки. В режиме ручного выбора новое включение заменяет предыдущее ручное наблюдение; запланированные конференции управляются отдельно.

## Счётчик Teams

Расширение читает явный числовой счётчик из интерфейса Teams на русском или английском. Оно не считает видеоплитки и строки списка: список может быть неполным или включать приглашённых. Сообщения, звук, видео и имена других участников не сохраняются и никуда не отправляются. В локальных настройках хранятся расписание, ссылки и указанное пользователем имя для гостевого входа; оно вводится в Teams при подключении.

**Распознавание ещё нужно проверить на вашей реальной конференции.** Microsoft меняет разметку Teams, и разные версии могут показывать счётчик по-разному. Перед использованием убедитесь, что расширение показывает правильное число. При сообщении «Счётчик не найден» откройте панель участников. Распознавание автоматическое; техническая настройка счётчика убрана из пользовательского интерфейса. Если счётчик по-прежнему не определяется, понадобится адаптация к разметке вашей версии Teams.

Пропавшее число не считается нулём. Неоднозначные и неактуальные данные сбрасывают историю и отсчёт подтверждения. Перерыв между чтениями больше 20 секунд также сбрасывает историю: при сильном ограничении фоновой вкладки автоматическое закрытие по оттоку может не сработать. При этом закрытие по времени продолжает работать.

## Ограничения

- Только веб-версия на `teams.microsoft.com`, `teams.live.com`, `teams.cloud.microsoft`; приложение Teams для Windows не поддерживается. Чтение счётчика внутри отдельных iframe и закрытых Shadow DOM не поддерживается.
- Компьютер должен бодрствовать, а Chrome — работать. Chrome может задерживать alarms; точность до секунды не гарантируется. После сна пропущенный таймер может сработать при пробуждении.
- После перезапуска Chrome текущие наблюдения нужно включить заново. Расписание будущих входов и настройки порогов сохраняются.
- После подтверждённого входа изменение URL останавливает наблюдение, даже если Teams изменил его внутри той же конференции. При автоматическом входе переходы внутри Teams допускаются до подключения.
- Закрытие вкладки не нажимает «Завершить собрание для всех». Фактическое отключение браузерного соединения и обновление статуса в Teams могут происходить с задержкой.
- Перед важным созвоном проверьте таймер на тестовой вкладке Teams. Эта версия не была проверена в живом звонке.

## Разработка

Без внешних зависимостей. Для проверки нужен Node.js 20+:

```powershell
npm test
npm run check
```

Тесты проверяют пороги, подтверждение и отмену оттока, потерю счётчика, устаревшие данные, распознавание счётчиков, таймер, восстановление service worker и защиту от закрытия вкладки с изменившимся URL. Дополнительно проверяются повторы, пропущенные и повторные запуски, восстановление расписания, гостевое имя, отключение медиа до входа, зал ожидания и полный сценарий открытия/подключения/независимого выхода нескольких вкладок. API Chrome и DOM Teams проверяются на заглушках; реальный интерфейс Teams требует отдельной проверки.

Используемые API: [Chrome alarms](https://developer.chrome.com/docs/extensions/reference/api/alarms), [tabs](https://developer.chrome.com/docs/extensions/reference/api/tabs), [content scripts](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts), [debugger](https://developer.chrome.com/docs/extensions/reference/api/debugger), [CDP Page](https://chromedevtools.github.io/devtools-protocol/tot/Page/). Панель участников: [справка Microsoft](https://support.microsoft.com/en-us/teams/meetings/use-meeting-controls-in-microsoft-teams).
