# Помощник Zoom для Windows

Расширение «Созвон» открывает Zoom по расписанию. Этот помощник управляет установленным Zoom Workplace через Windows UI Automation: распознаёт подключение, читает явный счётчик участников, выбирает «Выйти» и подтверждает выход. Он не завершает конференцию для всех и не убивает процесс Zoom.

## Установка

Нужны Windows 10/11, .NET Framework 4.8, Google Chrome и установленный Zoom Workplace. Расширение и Zoom должны работать от того же пользователя Windows, без запуска Zoom от администратора.

1. Обновите расширение кнопкой ↻ на `chrome://extensions`; версия должна быть **0.4.0**. Подтвердите разрешение на связь с приложениями компьютера, если Chrome попросит.
2. На карточке расширения скопируйте его ID (32 буквы).
3. В PowerShell из папки проекта выполните:

```powershell
& .\native\build.ps1
& .\native\install.ps1 -ExtensionId ВАШ_ID_РАСШИРЕНИЯ
```

Установщик регистрирует `com.sozvon.zoom` **только для указанного расширения** в `HKCU\Software\Google\Chrome\NativeMessagingHosts`. Права администратора не нужны. Файлы остаются в `native/bin`; если переносите папку проекта, запустите установщик заново. Никакой службы, задания планировщика Windows и сетевого сервера не создаётся.

4. В расширении выберите **Zoom — приложение Windows** и нажмите «Проверить помощник Zoom». Статус должен сообщить, что помощник подключён и Zoom найден.
5. В настройках самого Zoom заранее включите выключение камеры и микрофона при входе. Затем отметьте соответствующее поле в расширении. Это необходимо: запуск по ссылке может подключить медиа раньше, чем станут доступны кнопки интерфейса. Настройки Zoom автоматически не меняются. После входа помощник дополнительно нажимает распознанные кнопки выключения камеры/микрофона; неизвестное состояние не переключает.
6. Добавьте приглашение `https://us02web.zoom.us/j/12345678901?pwd=…`, время входа, повторение и условия выхода. Если ссылка содержит `pwd`, сохраните её полностью — это токен приглашения, а не текст пароля.

Сокращённые, корпоративные внешние и персональные `/my/`-ссылки сначала замените полной ссылкой приглашения с `/j/` и числовым ID. Поддерживаются домены `zoom.us`, `zoom.com` и их поддомены. Ссылки вебинаров `/w/` не поддерживаются.

## Поведение

- Расписание, повторы, пропуск опоздания более 5 минут — общие с Teams. Одновременно управляется **одна конференция Zoom**, другие задания Zoom получают понятную ошибку; Teams работает независимо.
- Рабочий стол должен быть разблокирован, компьютер бодрствовать, Chrome открыт, Zoom установлен. Заблокированный экран, закрытый Chrome, приостановленный процесс помощника и политика организации мешают управлению.
- Помощник запускает найденный `Zoom.exe` с реконструированной ссылкой `zoommtg://…/join`. Это адаптер к установленному клиенту, а не Meeting SDK. Совместимость схемы запуска и разметки UI Automation зависит от версии Zoom; живое подключение нужно проверить на вашем клиенте.
- Перед запуском помощник отказывается входить, если видит уже идущую конференцию Zoom. При подключении он выбирает только новое окно Zoom, которого не было до запуска, и привязывается к его HWND, процессу, времени запуска процесса и UI Automation RuntimeId. Если Zoom переиспользовал старое окно или не открыл доступные элементы управления, автоматизация может не подтвердить вход. Не открывайте другие конференции Zoom вручную во время автоматического подключения.
- Счётчик берётся только из подписи «Участники (N)» / «Participants (N)» или явного числа внутри соответствующего элемента управления. Счётчики отдельных владельческих панелей читаются только для того же окна конференции. Количество видеоплиток и имена в списке не используются. Пропавшие, расходящиеся, нулевые или устаревшие данные сбрасывают историю; отсутствие счётчика не мешает выходу по времени.
- Порог оттока, минимальное число ушедших, окно и подтверждение работают так же, как в Teams. Помощник проверяет их примерно раз в секунду, но UI Automation может задерживаться. Чрезвычайно короткие интервалы могут не набрать достаточно измерений. Во время подтверждения статус виден в расширении; там можно нажать «Остановить автоматизацию».
- Подключение подтверждается появлением кнопок конференции, а не фактом запуска процесса. В зале ожидания остаётся статус ожидания. MFA, CAPTCHA, вход в аккаунт, запросы прав и ручной код доступа не подтверждаются. Если ссылка не содержит нужный код и Zoom его запросил, введите его вручную. Имя из задания передаётся в ссылке, но отдельные формы конкретной версии клиента могут потребовать участия.
- После 15 минут неподтверждённого входа помощник пытается выйти из распознанного зала ожидания. Если время выхода наступило раньше, попытка выхода начинается тогда. Нераспознанные окна не закрываются вслепую.
- При выходе используются только явно распознанные кнопки «Выйти» / «Leave meeting». Отдельное окно подтверждения должно принадлежать управляемому окну. «Завершить для всех» не нажимается. Успех фиксируется после исчезновения привязанного окна или явного сообщения о завершении, а не после нажатия кнопки. Через 30 секунд без подтверждения показывается ошибка.
- «Остановить автоматизацию» оставляет Zoom открытым и отменяет его автоматический выход. Удаление задания также останавливает автоматизацию текущего запуска; пауза расписания затрагивает только будущие входы.
- При разрыве связи с Chrome помощник завершает работу, оставляя конференцию открытой. Восстановление текущего звонка после перезапуска Chrome не выполняется; будущие задания сохраняются. Не закрывайте Chrome до выхода из Zoom.

## Проверка

```powershell
& .\native\build.ps1 -Tests
& .\native\bin\Sozvon.ZoomTests.exe
npm test
```

Тесты C# используют искусственный адаптер вместо настоящего Zoom; они проверяют условия выхода, подтверждение, отмену, привязку к запуску, разбор ссылок/счётчиков и бинарные сообщения. Node.js также проверяет настоящий обмен сообщениями с собранным `.exe`, не открывая Zoom и не подключаясь к конференциям. Тесты API Chrome используют заглушки. Проверка реального входа и выхода требует установленного Zoom и тестовой конференции; она пока не выполнена.

Для удаления регистрации:

```powershell
& .\native\uninstall.ps1
```

Данные не отправляются на сторонний сервер. Расширение хранит ссылки и гостевое имя локально; помощник держит ID, токен приглашения и состояние запуска в памяти. Zoom получает ссылку и имя при подключении. Журнал сообщений, имён участников, аудио и видео не ведётся.

Документация: [Chrome Native Messaging](https://developer.chrome.com/docs/extensions/develop/concepts/native-messaging), [Microsoft UI Automation](https://learn.microsoft.com/en-us/dotnet/framework/ui-automation/ui-automation-overview), [настройки клиента Zoom](https://support.zoom.com/hc/en/article?id=zm_kb&sysparm_article=KB0060612).
